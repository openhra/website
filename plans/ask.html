What you can ask today

For each question OpenPlans can be asked, this page counts the insurer entries by state and plan year. The counts come from the data availability list that every OpenPlans server publishes.

Insurer entries by question and result

How to read these counts

Each insurer entry counts once per question. Answered means the source reports the data as available. Partial means the source reports it as partial. Not in the public source means the source reports it as unsupported. Unknown means the source reports it as unknown, or has no value. Unknown is not zero.

The questions are premiums, benefits and plan catalog, drugs, and providers. Medicare Part D plans are not in the availability list yet, so this page does not count them.

This page reads one saved file. It does not call a live server. The unknown counts list their reasons in plain words. A reason without listed words is shown as its code.
