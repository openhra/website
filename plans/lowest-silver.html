Lowest Silver by ZIP

Find the lowest gross monthly Silver premium for one person. Choose the plan year and age explicitly. This lookup uses non-tobacco rates for January 1 coverage.

The hosted lookup is awaiting operator activation. Until then, the minimum route may return an unavailable response. These forms open the API result as inspectable JSON. They do not calculate or save a quote in this page.

1. Look up the county

A ZIP can cross county lines. Open the county choices, then copy the matching five-digit county code into the second form. Choose the county where the person lives.


2. Request the minimum




Use the county FIPS code, including any leading zero.



Read the result

Use an amount only when status is calculated. The monthly price is lowest.monthly_cents divided by 100. Check candidate_count, the tied-plan count and provenance.snapshots for source retrieval dates and hashes. The JSON result keeps the source and rate-row evidence.

A null amount means the price is unknown. Only a filed zero is $0. The gross premium is the price before subsidies, not the subsidy benchmark or a bindable quote.
