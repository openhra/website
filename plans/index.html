Where OpenPlans has data

  • Self-hosted. Plan catalogs and filed rates for 30 federal-platform states and 19 state exchanges from the 2026 files, plus separate 2026 family-tier imports for New York and Vermont. The 2027 federal files cover 29 states; Georgia has a separate state import with CSV recovery off by default.
  • Hosted preview. 48 states and DC for 2026 and 29 states for 2027. NY and VT use separate filed-tier imports in self-hosted copies. The other state-exchange 2027 catalogs remain unknown. Georgia 2027 is quarantined.
  • Provider and drug evidence. Measured for some insurers in Florida, North Carolina and Texas. It is unknown everywhere else, including the hosted preview with 48 states and DC for 2026 and 29 states for 2027.

What's new on the hosted API

The hosted API at openplans.openhra.com runs OpenPlans v0.4.5. These changes affect its answers.

  • Reasons for empty provider and drug searches. If no NPPES release covers a ZIP's state, a provider search answers unknown with provider_registry_not_loaded. It used to return an empty list. Drug search adds terminology_status. Without a loaded RxNorm release it is unknown with rxnorm_terminology_unavailable. Over MCP, an unknown coverage, network or quote record keeps its reason in gaps.
  • ICHRA look-back on 2025 rates. With the look-back safe harbor, an ICHRA affordability check prices plans at January of the prior year. For a 2026 plan year that means 2025 rates. The hosted API now has them for 30 states. South Dakota's 2025 geography is unknown, and New York and Vermont have no 2025 data, so a look-back there answers unknown.
  • County-only quotes. Where a silver plan serves only part of a county, a quote without a ZIP returns location_requires_zip with reason zip_limited_service_area. The credit and net premium stay null until you send a ZIP. Gross premiums don't change.
  • More 2027 EHB amounts. Some 2027 plan files give the EHB percentage with up to 15 decimal places. Those plans used to answer unknown for the EHB portion of the premium. OpenPlans now calculates it.
  • Status page. openplans.openhra.com/status shows service health, data coverage by plan year and the age of each source.
  • Unloaded ZIPs. A ZIP outside the loaded data answers unknown with zip_not_in_loaded_geography instead of a server error. New York and Vermont answer state_catalog_not_loaded when no state catalog is loaded for the year.
  • Why plans are missing. Plan lists and quotes add issues, and the MCP tools search_plans and quote_plans add location_issues. Each gives a reason code when plans may be left out, such as zip_limited_service_area for a county-only request. The list is empty when no plan is known to be missing.
  • Medicare drug cost estimates. The code has them, but they are off on the hosted API. Self-hosted copies can turn them on.

01 / MCP · Public preview

Plan lookups.
With the evidence.

A catalog your agent can query.

The Model Context Protocol server is live as a public preview. Search the plan catalog, quote plans by age and ZIP, and look up provider and drug evidence with 15 read-only core tools. The public instance also offers get_status.

Answers include provenance. Provider and drug results may be unknown. Unknown never means "not covered".

Public preview. Coverage is limited. An outside acceptance run is still pending. OpenPlans v0.4.5 is available. The source is on GitHub.

15 core tools

searchfetch
Find records and retrieve their details for agent research.

Search the plan catalog and inspect one plan.
search_providerscheck_provider_network
Find providers and check published network participation.
search_drugscheck_drug_coverage
Find drugs and check published formulary evidence.
lookup_geographylist_carriers_networksget_data_status
Resolve geography, list carriers and networks, and inspect data availability.
quote_plans
Quote plans by age and ZIP, with provider and drug coverage per plan. The public endpoint has no provider or formulary files loaded, so that coverage is "unknown" there. Not a bindable quote.
quote_premiums
Quote a household with income, estimated tax credit and net premium. Subsidy figures are checked against source for Texas 2026 so far. Not a bindable quote.
check_ichra_affordability
Check whether an individual coverage HRA offer is affordable for one employee, with the cited rules.
search_medicare_plans
List the Medicare Advantage, Part D and special needs plans CMS lists for a county and contract year, where Medicare files are loaded.

get_status comes from the status plugin that the public instance enables, not from the core. It returns the public status summary as JSON. The same summary is at /status and /status.json. Operator detail needs a token and is not public.

Query the plan catalog

Native API base path

https://openplans.openhra.com/v1

Search plans for a ZIP code and plan year. The hosted preview has 48 states and DC for 2026 and 29 states for 2027. Houston, 2026:

curl --get 'https://openplans.openhra.com/v1/plans' \
  --data-urlencode 'zip=77002' \
  --data-urlencode 'year=2026'

Miami, 2027:

curl --get 'https://openplans.openhra.com/v1/plans' \
  --data-urlencode 'zip=33101' \
  --data-urlencode 'year=2027'

No account or API key. The public preview has 48 states and DC for 2026 and 29 states for 2027. It offers the catalog, quotes by age and ZIP and household quotes. A state or year without loaded data returns status: unknown and an empty plan list. Check data availability for the exact scopes and source limits. Send ages and a ZIP code to POST /v1/quotes. Add income to POST /v1/premium-quotes for subsidy estimates.

A public quote takes ages, a ZIP code or county and an optional tobacco flag per member, with at most 10 members and 10 plans. Dates of birth and names are refused there. OpenPlans does not log request bodies, income, ages or ZIP codes. Requests are rate-limited per address; a 429 answer carries Retry-After.

Build with the full API

Read the native API documentation for routes and response formats. For existing quoting integrations, start with the repository README.

Household quotes, the subsidy benchmark and ICHRA checks are open on the public preview, with the same per-address limits. An operator can require a token for them.

02 / Data integrity

Unknown stays unknown

  • When a file is missing, blocked or incomplete, the answer is unknown. OpenPlans never invents an answer or treats missing data as "not covered".
  • A state with no cited rating rule returns unsupported_rating_method rather than a guessed premium.
  • Each imported file becomes a snapshot with its URL, checksum and parser version. Failed replacements preserve the previous active data. Incomplete provider or drug sources keep explicit limits; missing evidence stays unknown.
  • OpenPlans labels fallbacks. If it finds a county through a secondary source, the answer names that source.

04 / Start with the source

Run OpenPlans on your server

Start with the README to configure Docker Compose and the data directory. A fresh database is empty. Import public-source snapshots before making API requests.

Get the code

git clone https://github.com/openhra/openplans.git
cd openplans

Source available · v0.4.5. Use the README for the current setup steps.

Import public data

OPENPLANS_RAW_READ_ONLY=false docker compose run --build --rm worker bootstrap --states TX,FL --years 2026,2027

After setup, this command imports two federal-platform states. Swap in any state from the CMS exchange files, for one year or both. A small first run is --states DE --years 2026. A state missing from the publication fails with a message instead of becoming an empty catalog. The README explains how to start the HTTP or stdio server.

Import a state exchange

OPENPLANS_RAW_READ_ONLY=false docker compose run --build --rm worker bootstrap --states GA --years 2026

State-exchange states use the same command with the 2026 files. Give the year when you mix them with federal-platform states. The hosted preview has 48 states and DC for 2026 and 29 states for 2027. Georgia is available for 2026; its 2027 source remains quarantined.

06 / Availability

What data is available?

Where OpenPlans has data, by state and plan year. Premiums count rate rows imported and checked against the public file. Providers and prescriptions count insurers whose published feeds OpenPlans could read. Each layer is a separate validated run, not market share, and the three never add up to one number. The hosted preview at openplans.openhra.com has 48 states and DC for 2026 and 29 states for 2027, with no provider or drug files. NY and VT keep separate filed-tier imports in self-hosted copies. California geography is partial, and some Massachusetts ZIP prefixes remain unknown.

08 / Publishers

For data publishers

If you saw this address in your server logs, it came from the OpenPlans fetcher. It identifies itself as:

openplans/0.1 (public health-plan source discovery; +https://plans.openhra.com/)
  • It downloads only files you publish for the public, such as machine-readable QHP indexes, formularies and provider directories.
  • It never pretends to be a browser and never works around access controls or bot checks. A 401 or 403 is recorded and not retried.
  • It retries only short-lived errors (timeouts, 429, 5xx), with backoff, and honours Retry-After.
  • Each file is stored once by checksum and reused, so the same file is not downloaded again without a reason.
  • OpenPlans is self-hosted, so requests with this identity may come from different organisations running their own copy.
