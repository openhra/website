# Implementation — coverage publication gate

`check.py` delegates all metric semantics to A, then binds the publication to its
safe selected-input manifest, complete selected scopes, report/source hashes and
scanner version/commit/input digest. It checks premium denominator row totals,
consistent repeated public member identities, future dates, prior-publication
scope/version/state preservation, unchanged scoped evidence assertions and dates,
and same-hash byte identity. It checks default heading/title/caption/map year and
reader year bindings before B's table/geometry checks.

`selftest.py` modifies isolated on-disk copies and repins dataset/ledger hashes for
semantic mutations. It invokes the publication checker as a subprocess, verifies
the named diagnostic, restores every copy and verifies original bytes.

The existing shell self-tests now call the valid normal-gate CLI, assert each
specific reason, and prove both clean and restored passes. The HTML parser now
checks buffered trailing tags and requires nonempty title text. Full mode invokes
A's tests and B's deterministic static controls; browser review remains separate.

The runbook assigns selection/scanning/commit review/publication to the
orchestrator and documents staging, atomic replacement, fallback refresh, stale
evidence and fix-forward behavior. Main and B were each merged locally once;
both were already ancestors. No protected content or scanner/data edits.
