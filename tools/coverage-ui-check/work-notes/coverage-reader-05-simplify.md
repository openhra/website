# Simplification — coverage reader

Kept one current dataset and one pending selection; no cache, service abstraction,
third-party map loader or dependency was needed. Reused A's generator output rather
than creating a competing fallback format. Detached table construction plus a single
synchronous paint avoids mixed snapshots. Per-state selection reuses the displayed
record and makes no request. Partial-source notes no longer append an irrelevant
undetermined-cause actor to an active source.

The browser checker uses the existing headed shared profile and only a matching
loopback tab. It records baseline overflow and native-popup limitations explicitly;
it does not report synthetic select changes as keyboard proof. Its temporary page,
response wrappers and negative visual mutations are removed or reloaded before the
final captures. No generated binaries or test dependencies were added.
