# Security policy

Do not report security problems in public issues. Report them privately through
private vulnerability reporting on
[openhra/openplans](https://github.com/openhra/openplans/security/advisories/new),
or through the contact section of <https://www.openhra.com/#contact>. See the
[OpenPlans security policy](https://github.com/openhra/openplans/blob/main/SECURITY.md)
for how reports are handled.

For a website report, include the affected page URL, steps to reproduce the problem
and the date or commit you tested. Remove credentials and personal health information.
