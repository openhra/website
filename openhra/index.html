OPEN SOURCE · SELF-HOSTED

Open building blocks.
For health benefits.

Individual coverage HRAs let employers give people money for a health plan they choose themselves. Running one takes plan, premium, subsidy, drug and provider data, often available through paid APIs. OpenHRA builds open-source tools that provide this data from public sources. Anyone can run them.

OpenPlans is a self-hosted API for US marketplace plans, household premiums, subsidy estimates, drug coverage and provider networks. It uses only CMS, Census, NPPES, RxNorm and insurer files. A compatibility API supports existing quoting integrations.

02 / How we work

Principles

  • Public data only. Every number comes from a public file from a government agency or insurer. We keep the source.
  • Unknown stays unknown. We report missing or blocked data as unknown. We never guess or fill it in.
  • Run it yourself. The open-source code runs in containers on your own server. The core data needs no account or key.
  • Checked against the source. Before shipping a release, we compare every value with the raw public files.
  • Respect publishers. Our downloaders identify themselves honestly, respect access controls and avoid repeat downloads.
